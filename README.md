# W6 Pings

Karlie's dashboard for the Workspace6 sponsor outbound system: daily ping count, draft approvals, replies handed to her, follow-up rules, results.
Code only, no secrets. Airtable (W6 Media base) is the database. Deployed on Render; env vars AIRTABLE_TOKEN, SECRET_KEY, DASH_USERS.
The engine and data live in the private repo dannyzeemedia/karlie-outbound.
